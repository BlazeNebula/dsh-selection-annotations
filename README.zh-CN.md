# 划词批注（dsh-selection-annotations）

[English](README.md) · **简体中文**

> 在 DSH Web 界面里选中任意文字，写一句批注，随下一条消息一起发出；模型逐条答复，答复卡片直接回到对话里。
> 批注是独立的机器可读数据块，你的消息正文不会被改写。

一个 [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）插件。零依赖，不改 DSH 本体。

## 它能做什么

- **选中即批注**：助手回复、用户消息、工作区文件预览，以及本插件自己的「已发送」与「答复」卡片。
- **高亮与编号**：原文上保留淡色高亮和编号角标；点角标直接修改那一条。
- **精确定位**：每条批注记下字符区间；工作区文件另记路径与行号。模型能看到「批注挂在哪一段的哪个位置」。
- **带图批注**：每条最多 4 张图，单张 8 MB；默认压缩成 JPEG，透明区域填白。
- **随消息发送**：批注作为 `批注.json` 附件随消息发出，宿主再把它拆成一条独立的 JSON 消息交给模型。
- **已发送回看**：每轮固定在「已完成」上方显示一张「已发送的批注」卡片，默认展开。
- **逐条答复**：模型用工具提交答复，每条带判定（采纳 / 部分采纳 / 不采纳 / 需澄清）；答复卡在「已完成」下方。
- **收展**：两个区域都有自己的开合；你收起「已完成」时，只收起答复卡的正文，标题仍留在外面。
- **总览面板**：输入框旁的「批注 N」胶囊打开总览，可拖动排序、编辑、删除、清空。
- **中英双语**：跟随 DSH 的界面语言切换。
- **右键菜单**：正文选区上右键，可直接「批注选中文字」或「复制」。

## 安装

插件市场暂未收录，用本地目录安装：

1. 打开 DSH 的「插件」页，选择从本地目录安装，填本仓库路径（例如 `E:\heshujiang\Develop\dsh-selection-annotations`）。
2. 装好后**完全退出 DSH**（包括托盘图标）再启动；只刷新页面不会重新加载插件代码。

升级插件后同样需要完全退出再打开。

## 使用

### 划一句、写一条

1. 在任意可读文字上拖选。
2. 选区下方出现「批注」按钮，点它。
3. 在弹层里写批注；可以留空——那就只是标记原文。
4. 继续选下一处，或直接发送消息。

批注会跟着下一条消息走，不会插进你的正文。

### 批注弹层

- 点框外等于保存；按 Esc 取消。
- 新划出来、既没写字也没加图的批注，点框外会直接丢弃，不会留下空条目。
- 输入框高度随内容增长；手动拖过高度后不再自动调整。
- 鼠标在已批注的原文上停留 500ms 会打开编辑框；这种悬停打开的，移开鼠标会自动保存并关闭。

### 图片

- 弹层里可粘贴或拖入图片；每条最多 4 张、单张不超过 8 MB。
- 默认按 80% 质量压缩成 JPEG；最短边不超过 100 像素的图保持原样。
- 缩略图点一下全屏查看，点任意处或 Esc 关闭。
- 图片随草稿保存，刷新或切会话后还能继续发；草稿超过 3.5 MB 时先丢最旧的图片，文字保留。

### 总览面板

输入框旁的「批注 N」胶囊打开总览：

- 每条显示出处、引用原文、批注文字与缩略图。
- 拖动手柄可以调整顺序。
- 悬停出现「编辑」「删除」；底部有「清空」。
- 面板底部显示构建标记（插件 ID 与版本），用来确认页面加载的是哪一版代码。

### 已发送的批注

- 每轮一张卡片，位置固定在那一轮的「已完成」上方。
- 卡片里列出本轮发出的每一条：引用原文、批注、图片。
- 默认展开；点标题行收起或展开。
- 在卡片里也能继续划线批注，锚点会记到「已发送」区域的具体条目与字段上。

### 批注答复

- 模型处理完一批批注后调用 `annotation_replies` 工具提交答复。
- 答复卡片按条展示：来源（引用原文与批注）、判定徽标、理由、下一步。
- 卡片在「已完成」下方，默认展开；点标题行独立收起或展开。
- 你收起「已完成」时，答复卡片只收起正文，标题与卡片本身仍留在外面；再点「已完成」展开也不会强行改回你手动设置的状态。
- 在答复卡片里同样可以划线批注，锚点会记到批次、批注编号与字段上。
- 模型若忘了调用工具，回合结束时会收到一次提醒。

### 右键菜单

在正文选区上右键，会出现「批注选中文字」与「复制」；没有选区时保留系统菜单。

### 语言

界面文案与默认批注指令都跟随 DSH 的语言设置，中文与英文两套。

## 批注指令

插件发给模型的说明文字（字段含义、位置口径、必须逐条答复的约束）可以在「设置 → 插件 → 划词批注」里修改。

- 默认指令是分小节的要点格式，便于人工阅读和编辑。
- 改过之后，点「恢复默认」回到内置版本。
- 默认指令会随界面语言切换；如果你保存过自定义指令，以保存的为准。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `annotation_replies` | 提交这一批批注的逐条答复，每项包含 `index`、`verdict`、`reason`、`next` |

`verdict` 取 `accepted`（采纳）、`partial`（部分采纳）、`rejected`（不采纳）、`needs_info`（需要澄清）。

## 设置

「设置 → 插件 → 划词批注」提供：

- 图片：压缩开关、质量（0–100）、触发压缩的最短边阈值。
- 批注指令：编辑、恢复默认。

## 数据与隐私

- 未提交的草稿按会话保存在浏览器 `localStorage`；不可用时退回内存，刷新即丢。
- 已发送批注的台账也在浏览器 `localStorage`，按会话分键。
- 答复由宿主写入本机 `$DSH_HOME/selection-annotations/sessions/<会话 id>.json`。
- 批注图片作为消息附件保存在本机会话记录里。
- 插件不发起外部网络请求；所有数据只在本机与当前 DSH 会话内流转。
- 宿主单条负载上限默认 512 KB（`maxPayloadBytes` 可配）。

## 与上游的关系

本仓库 fork 自 [2A5F/dsh-selection-annotations](https://github.com/2A5F/dsh-selection-annotations) 的 1.1.0，在此基础上增加了逐条答复、已发送回看、收展联动、总览面板改版、中英双语、按轮次定位与 DSH 0.2.2 适配。

上游后来发布了 2.x，方向不同（例如把批注挂到输入框的引用块上）；两边功能不一一对应。

## 开发

浏览器侧源码在 `src/`，构建后生成单文件 `client.js`（DSH 只加载这一个文件）：

```
src/entry.js          DSH loader 入口
src/plugin.js         组合根：注入依赖、注册槽位与生命周期
src/core/             按职责拆分的模块（会话、草稿、台账、远端同步、锚点、卡片、面板、样式、文案等）
scripts/build.mjs     esbuild 打包
scripts/check-build.mjs  校验 client.js 与 src/ 一致
lib/index.js          宿主半边：认领批注附件、注入 JSON 消息、答复存储与工具
```

- 改完 `src/` 后运行 `npm run build`，再运行 `npm test`（含构建一致性校验与 76 项测试）。
- 不要直接改 `client.js`，它是构建产物。
- 构建使用 esbuild，React 作为 external，由 DSH 注入。

## 已知限制

- 定位依赖 DSH 的私有 DOM 锚点，DSH 大版本升级可能需要适配。
- 历史轮次被虚拟化时，卡片位置依赖轮次属性，仍以 DSH 实际渲染为准。
- 已发送与答复卡片覆盖升级后发出的批注；更早记录的迁移按尽力处理。
- iframe、canvas 里的文字无法划线。
- 中文文案已接入语言服务，英文翻译如与界面不一致，以中文为准。
